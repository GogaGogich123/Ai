## 🔒 Что делать, если ключ уже утёк?

Если ваш API ключ попал в публичный репозиторий:

1. **Немедленно отзовите ключ:**
   - Перейдите: https://makersuite.google.com/app/apikey
   - Удалите старый ключ
   - Создайте новый

2. **Удалите из истории Git:**
   ```bash
   # Сложно! Лучше сразу отозвать ключ
   ```

3. **Проверьте использование:**
   - Google Cloud Console → API usage
   - Проверьте нет ли подозрительной активности
